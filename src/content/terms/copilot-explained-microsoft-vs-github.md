Copilot is a brand name that Microsoft and GitHub use for several different AI products. The free Microsoft Copilot app answers questions, Copilot in Microsoft 365 helps inside Word, Excel, Outlook and Teams, and GitHub Copilot helps people write and review code. They share a name but not a price, a login or a job, so "just use Copilot" can mean three different things.

## One name, several products

Our article [What is an AI copilot?](/terms/what-is-an-ai-copilot/) explains the idea behind the word: the AI suggests, a person decides. This article is the practical guide to the products that carry the name.

Microsoft's own support page sorts its side into three groups: Microsoft Copilot (free), Copilot in individual Microsoft 365 plans, and Copilot in Microsoft 365 business plans. GitHub Copilot is separate again.

## Microsoft Copilot: the free assistant

**Microsoft Copilot** is a general [chat assistant](/terms/ai-assistants-agents-and-bots-map/), free of cost. Microsoft says it is best for general questions, web tasks and people trying AI for the first time. On Windows it comes as a free app.

It is the right place to start if you only want to ask questions, draft text or try AI without paying.

## Copilot in Microsoft 365: inside your office apps

**Copilot in Microsoft 365** works inside the apps you already use for documents and email. It can draft in Word, analyse a sheet in Excel or summarise a thread in Outlook. In business plans it can also use your work files, emails and chats.

There are two families of plans. Prices from Microsoft's pages on 20 November 2026, before limited-time offers:

| Plan | For | Price |
|---|---|---|
| Microsoft 365 Personal | One person | $9.99/month |
| Microsoft 365 Family | A household | $12.99/month |
| Microsoft 365 Premium | One person, higher AI limits | $19.99/month |
| Microsoft 365 Business Standard with Copilot | Companies | $23.50 per user/month, paid yearly |
| Microsoft 365 Business Premium with Copilot | Companies, more security | $32.00 per user/month, paid yearly |

Microsoft lists Copilot in the Personal, Family, Premium and Pro individual plans, with usage limits that grow with the plan. The business prices are higher if you pay monthly. Offers and limits change, so check Microsoft's page before buying.

## GitHub Copilot: for code

**GitHub Copilot** belongs to GitHub, which Microsoft owns, and it is a different product with its own plans. It suggests code as you type, answers questions about a project, reviews pull requests, and includes a coding agent.

GitHub describes the agent's job like this: it researches a repository, proposes a plan, edits files and prepares a pull request for your review. Other companies' coding agents can also work alongside it on GitHub.

From GitHub's plans page on 20 November 2026:

- **Free**: $0, with 2,000 code completions a month.
- **Pro**: $10 per user per month.
- **Pro+**: $39 per user per month, with more included usage.

It sits in the same family as the [coding agents](/terms/coding-agents-app-builders-and-workflow-agents/) Claude Code, Codex, Cursor and Devin.

## Which Copilot do I need?

- **You just want to ask questions and draft text:** the free Microsoft Copilot, or any chat assistant.
- **You live in Word, Excel and Outlook:** a Microsoft 365 plan that includes Copilot; Personal or Family at home, a business plan at work.
- **You write code:** GitHub Copilot, starting with the free plan.

Many people need only one. A company might pay for both: Microsoft 365 for office staff and GitHub Copilot for developers.

## Is Copilot an agent?

Partly. Most Copilot features suggest and wait for you, which fits the copilot idea. But GitHub Copilot's coding agent takes a task and works through many steps on its own, and Microsoft's Copilot Studio now builds agents too. The name stays the same while the products move along the scale from assistant to agent.

## Sara and the three Copilots

Sara, a freelance designer, hears "just use Copilot" from three people in one week.

Her client means Microsoft 365: the client's team shares files in Word and Teams, so Sara uses Copilot there when she works inside the client's workspace. Her developer friend means GitHub Copilot, which could help with the code of Sara's portfolio site; she tries the free plan. Her neighbour means the free Microsoft Copilot app, for quick questions.

Once she knows which Copilot each person means, the advice makes sense. She pays for none of them yet.

## Recap

- Copilot is a brand covering several products, not one tool.
- Microsoft Copilot is the free chat assistant for questions and drafting.
- Copilot in Microsoft 365 works inside Word, Excel, Outlook and Teams, in individual plans from $9.99/month and business plans from $23.50 per user/month (Nov 2026).
- GitHub Copilot is for code, with a free plan, Pro at $10 and Pro+ at $39 a month, and a coding agent that prepares pull requests.
- Pick by job: questions, office documents or code.
