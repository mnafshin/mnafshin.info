"Copilot" is two things at once: a product name and a design idea. As a product, Copilot with a capital C is a brand that Microsoft and GitHub use for many very different tools. As an idea, a copilot is an AI that suggests while a human decides. Telling the two apart answers the most common question at work: which Copilot does someone mean, and who is in charge of what it does?

## Three meetings, one word

On Monday, the IT team says: we are rolling out Copilot next month. On Tuesday, a vendor says: our app now comes with a copilot. On Wednesday, a developer says: Copilot opened a pull request while I slept. A pull request is a proposed change to the code.

Same word, three meetings. Each one fits into one of two boxes, *product* or *idea*, and the rest of this article sorts them.

## The product: a brand that covers many tools

In June 2021, GitHub showed a preview of [GitHub Copilot](https://github.blog/news-insights/product-news/introducing-github-copilot-ai-pair-programmer/) and called it an AI pair programmer. It suggested whole lines or entire functions inside the code editor.

Microsoft, which owns GitHub, then used the name almost everywhere. In November 2023, Microsoft 365 Copilot became available to businesses, and Bing Chat was renamed Copilot. There were copilots for security and for business apps too. So Copilot with a capital C is usually a brand, and one brand covers many different products.

## Monday: which product?

Two of these products get mixed up all the time. **Microsoft 365 Copilot** is for office work: it lives in Word, Excel, Outlook and Teams, drafts documents and emails, and summarises meetings. Many work Microsoft accounts already include a basic version called Copilot Chat.

**GitHub Copilot** is a different tool for people who write code. It suggests code as you type, answers questions about a project and can work on tasks you hand it. Microsoft's own [overview](https://learn.microsoft.com/en-us/copilot/microsoft-365/microsoft-365-copilot-overview) lists it as a separate product with its own licence.

So Monday's rollout is a product. For an IT team that runs Word and Outlook, it is most likely Microsoft 365 Copilot. The useful follow-up is: which Copilot, and what will it be able to see?

## Tuesday: the idea, the AI suggests and you decide

In 2023, Microsoft's chief technology officer, Kevin Scott, gave a [simple definition](https://news.microsoft.com/source/features/ai/microsoft-outlines-framework-for-building-ai-apps-and-copilots-expands-ai-plugin-ecosystem/): a copilot is an application that uses modern AI, with a conversational interface, and assists you with cognitive tasks. In plain words, you chat with it, and it helps with thinking work.

The key word is *assists*. The name comes from the cockpit: a copilot helps, but someone else is in command. GitHub described it as keeping you firmly in the pilot's seat.

On a real screen, that looks like grey suggested code next to what you are typing. GitHub's [documentation](https://docs.github.com/en/copilot/responsible-use/copilot-code-completion) says suggestions are visually distinct and only applied when you explicitly accept them. In an office app, the copilot drafts the email, and you decide whether to send it.

Tuesday's vendor, with a small c, means this idea: an AI helper inside their own app that suggests while you decide.

## Does the idea save time?

In a [well-known 2022 experiment](https://arxiv.org/abs/2302.06590), 95 developers were given one task: write a small web server in JavaScript. The group with GitHub Copilot finished 55.8% faster.

The small print matters. It was one task, in one language, and the paper did not look at the quality of the code. The speed is real in that test; checking the result is still your job.

## Wednesday: when the product becomes an agent

The product name stayed the same, but what is inside the box changed. In May 2025, GitHub previewed the [Copilot coding agent](https://github.blog/changelog/2025-05-19-github-copilot-coding-agent-in-public-preview/): you assign it an issue, a to-do ticket for the code, and it works in the background in its own cloud environment, then asks you to review its pull request.

That is Wednesday's meeting. It is a worker taking many steps on its own, not a suggestion next to your cursor. Microsoft went the same way: its Copilot Studio, first used to build custom copilots, now builds agents too. The brand covers both helpers that suggest and agents that act.

## Who presses the button?

One question sorts them. In the copilot idea, the AI suggests and you approve each step: you press the button every time. With an agent, you give it a goal, it takes several steps by itself, and you check the result at the end. A copilot waits for you; an agent keeps going.

Neither is better; they need different kinds of checking. The same product can do both, depending on which feature is turned on.

## Recap

- Copilot with a capital C is a brand that covers many different products.
- Microsoft 365 Copilot is for office work; GitHub Copilot is a separate coding tool with its own licence.
- As an idea, a copilot means the AI suggests and a human decides each step.
- When the AI takes several steps on its own, it has become an agent, even if the name stays.
- At work, ask: product or idea, which product, who approves each action, what can it see, and who checks the output.
